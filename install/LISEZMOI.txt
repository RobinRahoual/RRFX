CUTFX - panneau Premiere Pro par @robin.rahoual (Instagram)

INSTALLATION
1. Ferme Premiere Pro.
2. Windows : double-clique sur "Installer CutFX (Windows).bat"
   (si Windows affiche "Windows a protege votre ordinateur" :
    "Informations complementaires" puis "Executer quand meme").
   Mac : clic droit sur "Installer CutFX (Mac).command" > Ouvrir.
   Laisse le dossier CutFX dans le meme dossier que le script.
3. Lance Premiere Pro, puis : Fenetre > Extensions > CutFX

Il faut un calque de reglage dans le projet :
Fichier > Nouveau > Calque de reglage (une fois par projet).

MISE A JOUR
Relance simplement le script d'installation de la nouvelle version :
il remplace l'ancienne. Tes effets perso sont gardes
(Documents/CutFX/library.json).

DESINSTALLATION
Supprime le dossier CutFX de :
  Windows : %APPDATA%\Adobe\CEP\extensions
  Mac : ~/Library/Application Support/Adobe/CEP/extensions
