RRFX - panneau Premiere Pro par @robin.rahoual (Instagram)

INSTALLATION
1. Ferme Premiere Pro.
2. Windows : double-clique sur "Installer RR FX (Windows).bat"
   (si Windows affiche "Windows a protege votre ordinateur" :
    "Informations complementaires" puis "Executer quand meme").
   Mac : double-clique sur "Installer RR FX (Mac).command".
   Si macOS dit "Apple n'a pas pu confirmer..." : clique sur "Termine",
   puis Reglages Systeme > Confidentialite et securite > tout en bas
   "Ouvrir quand meme". Ou, dans le Terminal : tape "sh " (avec l'espace),
   glisse le fichier .command dans la fenetre, puis Entree.
   Encore plus simple, sans rien telecharger a la main (Terminal) :
   curl -fsSL https://raw.githubusercontent.com/RobinRahoual/RRFX/main/installer-mac.sh | sh
   Laisse le dossier RRFX dans le meme dossier que le script.
3. Lance Premiere Pro, puis : Fenetre > Extensions > RR FX

Il faut un calque de reglage dans le projet :
Fichier > Nouveau > Calque de reglage (une fois par projet).

MISE A JOUR
Relance simplement le script d'installation de la nouvelle version :
il remplace l'ancienne. Tes effets perso sont gardes
(Documents/RRFX/library.json).

DESINSTALLATION
Supprime le dossier RRFX de :
  Windows : %APPDATA%\Adobe\CEP\extensions
  Mac : ~/Library/Application Support/Adobe/CEP/extensions
